1Department of Materials Science and Engineering, The Pennsylvania State University, University Park, PA 16802, USA
†Distinguished Professor of Materials Science and Engineering

Abstract

Fitting a black-hole ringdown with a single quasi-normal mode (QNM) started too early returns biased remnant parameters. We quantify this bias for GW250114 by sliding the analysis start time t0 across 21 overlapping epochs and tracking the inferred Kerr mass, spin, and horizon area. The single-mode effective mass begins at 76.0 M☉ (source frame) / 81.8 M☉ (detector frame)—above the total pre-merger mass M1 + M2 = 66.4 M☉, an unphysical value for any true remnant—and decreases monotonically (Spearman rank correlation ρs = -0.992, block-permutation p < 0.001), crossing the global posterior anchor M∞ = 63.8 M☉ near 2.7 ms and undershooting it at late times as signal-to-noise degrades.

A controlled numerical-relativity injection reproduces the identical overshoot-to-undershoot trajectory about its known true mass, confirming the trajectory as an inference bias rather than physical evolution. Three independent tests attribute the early excess to unmodeled overtone spectral content (Isaacson energy balance, overtone accounting, and spectral correlation). The inferred horizon area exceeds the progenitor sum at every epoch (Aeff / (A1 + A2) ≥ 1.365), fully consistent with Hawking’s area theorem. Because the inference chain operates in the detector frame, all physical quantities are consistently mapped to the source frame (z = 0.076), resolving the false-convergence illusion.

The Three Empirical Pillars

Pillar 1

Magnitude: The 3.87 σ Impossible Excess

At the earliest start time (t0 = 0 ms), the single-mode template infers a mass 14.4% greater than the combined progenitor black holes. No physical remnant can be heavier than the matter that collapsed to form it. This provides a model-independent proof that the early trajectory represents inference bias.

Pillar 2

Decay & Crossing: Monotonic Relaxation

Across 21 sliding epochs (stepped by 1M = 0.337 ms, 4.59 ms window), the effective mass decays monotonically (ρs = -0.992, p < 0.001), crossing the full inspiral-merger-ringdown posterior anchor M∞ at ~2.7 ms before entering noise-dominated undershoot.

Pillar 3

Origin: Overtone Absorption & NR Validation

A synthetic numerical relativity injection with fixed final mass pushed through the identical pipeline reproduces the exact overshoot trajectory. Multi-mode fitting (2,2,0 + 2,2,1 + 2,2,2) resolves 62% of the initial departure, proving the excess is overtone energy absorbed by the single mode.

Reproducibility & Technical Pipeline

The entire analysis is 100% reproducible. The code, test battery, and timeseries data are packaged in the repository under paper/:

# 1. Extract timeseries parameters from pyRing and Bilby posteriors
python paper/code/analysis/r1_extract.py

# 2. Fit single- and multi-exponential relaxation models
python paper/code/analysis/r1_fits.py
python paper/code/analysis/r2_compare.py

# 3. Generate publication suite figures (FIG 1-5)
python paper/code/figure_generation/bh_make_ringdown_publication_suite.py

# 4. Run the complete 21-test statistical robustness battery
python paper/code/tests/run_all_tests.py

# 5. Build and verify the PRD manuscript with consistency gates
python paper/code/manuscript_build/_build_prd.py
python paper/code/manuscript_build/_fix_refs.py
