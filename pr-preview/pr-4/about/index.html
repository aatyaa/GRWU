About GRWU

GRWU is a visual on-ramp to gravitational-wave data analysis. Each article takes one step of the analysis pipeline, from reading detector data to measuring a merger, and builds intuition for it on real data before handing you the tools researchers use.

The articles follow the same path as the Gravitational Wave Open Data Workshop. The goal is that a reader who finishes the core track is ready for the workshop's data challenges.

Three levels of depth

Every idea starts with intuition: figures you can move and signals you can hear. You can open the mathematics behind it, and then the Python code that computes it, without losing your place in the article.

Data

Strain data and event catalogues come from the Gravitational Wave Open Science Center, which publishes data from the LIGO, Virgo and KAGRA observatories.
